六格观察法的目标不是“少看几张贴纸”，而是**不转动整颗魔方，仅凭正面与右面顶行的六枚贴纸，认出 PLL 案例和镜像方向**。这样可以把 OLL 结束到 PLL 起手之间的停顿，压缩成一次固定范围的扫视。

本教程默认你已经会完整 OLL，并至少认识 21 个 PLL 的名称。这里不重新教授 PLL 公式，而是专门解决三个问题：眼睛先看哪里、如何把候选缩小、认出案例后怎样避免 AUF 错位。

> 顶面颜色不必固定为黄色。全文示意图采用黄顶、绿前、红右配色，但判断依据始终是同色、相邻色和相对色，不是某个绝对颜色。

## 先把网上教程分成三条路线

多篇六格观察教程看似各讲一套，实际可以归为三种组织方式：

| 路线 | 先看什么 | 优点 | 容易卡住的地方 |
| --- | --- | --- | --- |
| 角块置换优先 | 先用四颗可见角贴分成角归位、对角换角、相邻换角 | 候选一次缩到 4、5 或 12 个，逻辑稳定 | 相邻换角分支仍需继续看色块与颜色关系 |
| 特征优先 | 按 3 格条、车灯、2 格块、书挡的固定顺序扫描 | 熟练后很快，看到强特征即可停止 | 初学时容易同时数太多特征 |
| 逐案例记忆 | 为每个 PLL 记四个观察方向的图像 | 与训练器衔接直接，适合最后形成瞬时识别 | 若死记绝对颜色，换配色或换观察方向就会失效 |

本篇以 [Sarah Strong 的指南](https://sarah.cubing.net/3x3x3/pll-recognition-guide)为主线：**先判角块置换，再按可见色块细分**；在每个分支内采用 [Mark Rivers 的固定扫描顺序](https://cubing.pt/wp-content/uploads/2017/03/pll2side-20140531.pdf)；最后用四方向案例卡把规则练成图像识别。三条路线各自解决一层问题，不需要三选一。

## 六格到底是哪六格

完成 OLL 后，保持顶面朝上，视线横跨正面与右面的交界。你要读的是：

`正面：角—棱—角｜右面：角—棱—角`

靠近两面接缝的格叫**内侧**，最左和最右的格叫**外侧**。六格法不要求侧面中心进入视野；识别案例时先读贴纸之间的关系，确定 AUF 时再把特征与中心对齐。

<!-- tutorial-widget:pll-recognition {"group":"features"} -->

先统一六个高频词：

- **车灯（headlights）**：同一面两颗角贴同色。中间的棱贴是否同色，不影响“车灯”成立。
- **3 格条（3-bar）**：同一面的角、棱、角连续三格同色。它同时也是一组车灯，但信息更强。
- **2 格块（2-bar / block）**：相邻的角贴与棱贴同色。靠接缝是内侧块，远离接缝是外侧块。
- **书挡（bookends）**：六格最外侧的两颗角贴同色，像从两端夹住中间四格。
- **棋盘（checker）**：两种颜色交替出现。教程会区分棋盘出现在六格内侧还是外侧。
- **相邻色 / 相对色**：在你的魔方配色中相邻或互为对面的颜色。常见配色的侧面相对色是红—橙、绿—蓝。

> “色块”只表示两枚或三枚贴纸彼此同色，不表示它们此刻已经与侧面中心对齐。把“同色关系”和“AUF 是否完成”分开，是六格观察稳定的关键。

## 第一眼只判角块置换

先忽略两颗可见棱贴，只读四颗角贴。Sarah 的核心结论是：四颗可见角贴一定足以把 PLL 分入下面三组。

<!-- tutorial-widget:pll-recognition {"group":"corner-families"} -->

固定判断顺序：

1. **两面都有车灯**：四颗角全部归位，候选只有 `H / Ua / Ub / Z`。
2. **两面上的角贴都分别互为相对色**：对角换角，候选只有 `E / Na / Nb / V / Y`。
3. **其余情况**：相邻换角。你会看到只有一面有车灯，或只有一面的角贴是相对色。

不要在这一步猜具体 PLL。先把分组说出来，再继续扫特征。眼睛每次执行同一流程，速度才会稳定。

## 第二眼按强特征顺序扫描

在已经确定的角块分组内，始终按下面顺序找第一个成立的特征：

1. `3 格条`
2. `车灯`
3. `2 格块`
4. `书挡`
5. `棋盘、相邻色 / 相对色、可见颜色数量`

这个顺序的价值在于**及早停止**。例如已经看见 3 格条，就不必先数遍所有 2 格块；没有 3 格条再进入下一项。真正的瞬时识别不是同时处理所有信息，而是让最强线索先淘汰最多候选。

## 分支一：角块归位的四个 EPLL

这组最适合先练。两面始终都有车灯，只需判断四颗棱块如何置换。

| 先看 | 再看 | 结果 |
| --- | --- | --- |
| 两面都是 3 格条 | 无需再看 | PLL skip，顶层已经复原 |
| 只有一面是 3 格条 | 另一面中间棱贴与条的颜色是相邻还是相对 | `Ua / Ub`，方向互为镜像 |
| 没有 3 格条，左右各出现一枚“相对色棱” | 两边都成立 | `H` |
| 没有 3 格条，也没有相对色棱 | 棋盘只偏左或只偏右是 `Ua / Ub`；否则是 `Z` | `Ua / Ub / Z` |

“相对色棱”指中间棱贴与本面车灯颜色互为相对色。若只有一个 3 格条，可以直接用 Sarah 的方向规则：

- 条在左边：右侧是相对色棱为 `Ub`，是相邻色棱为 `Ua`。
- 条在右边：左侧是相对色棱为 `Ua`，是相邻色棱为 `Ub`。

下面每张卡都展示同一案例经过 `U / U2 / U'` 后的四个观察方向。颜色只是一个实例，练习时要说出“条在左、相对色在右”，不要背“红红红”。

## 分支二：对角换角的五个案例

确定两面角贴都成相对色后，只需数可见的 2 格块。这个分支比相邻换角短得多：

| 可见 2 格块 | 位置关系 | 案例 |
| --- | --- | --- |
| 两个 | 都在内侧 | `V` |
| 两个 | 都在外侧 | `Y` |
| 两个 | 两块集中在同一侧，接缝角属于左块 / 右块 | `Na / Nb` |
| 一个 | 外侧块 | `V` |
| 一个 | 内侧块 | `Y` |
| 没有 | 六格内侧形成棋盘 | `V` |
| 没有 | 六格外侧形成棋盘 | `Y` |
| 没有 | 内外都没有棋盘 | `E` |

`Na` 与 `Nb` 是镜像。把六格在脑中拉成一条横带：接缝处那颗完整可见角参与左侧色块时记作 `Na`，参与右侧色块时记作 `Nb`。若你的常用公式命名方向与公式库不同，以自己公式的起手方向为准，但左右判断必须始终一致。

## 分支三：相邻换角的十二个案例

这一组包含 `A / F / G / J / R / T`，也是六格法最需要分层练习的部分。不要一次背十二张图，先按**车灯数量和色块数量**切成五类。

| 六格结构 | 关键的第二线索 | 候选与判断 |
| --- | --- | --- |
| 无车灯、两个块 | 有 3 格条或一内一外块 | `Ja / Jb`；外侧块在左偏 `Ja`，在右偏 `Jb` |
| 无车灯、两个内侧块 | 看外侧角的相对色落在哪边 | `Aa / Ab` |
| 一组车灯、一个内侧块 | 车灯中间棱是相邻色则为 `R`，按块的左右分 `Ra / Rb`；否则为 `T` | `Ra / Rb / T` |
| 一组车灯、一个外侧块 | 六格仅三种颜色为 `A`，四种颜色为 `Ga / Gc`；再按块的左右分镜像 | `Aa / Ab / Ga / Gc` |
| 无车灯、一个 3 格条 | 无需再看 | `F` |
| 无车灯、一个内侧块 | 块旁角为相邻色是 `Ga / Gc`，为相对色是 `Gb / Gd`；按块左右分镜像 | 四个 `G` |
| 无车灯、一个外侧块 | 三色且块旁是相对角为 `Gb / Gd`；三色且块旁是相邻角为 `Ra / Rb`；其余用 `A / T` 排除 | `A / G / R / T` |
| 有车灯、没有块 | 先看车灯中间棱是相对色还是相邻色，再看三色 / 四色和棋盘 | `A / G / R` |
| 无车灯、没有块 | 三种颜色直接是 `F`；四种颜色看相对角出现在内侧还是外侧 | `F / Ga / Gc / Ra / Rb` |

最后两类是最容易停顿的视角，可以再拆成两条口令：

- **车灯但无块**：车灯夹相对色棱，优先想 `Gb / Gd`；夹相邻色棱时，三色想 `R`，四色有棋盘想 `G`、无棋盘想 `A`。
- **无车灯也无块**：三色是 `F`；四色时，相对色角落在外侧想 `Ga / Gc`，落在内侧想 `Ra / Rb`。

左右镜像不要另背一整张颜色图。先认出家族，再观察唯一色块、车灯或相对色角位于六格左半还是右半。下面的四方向卡用于把这一步练成直觉。

## 认出案例不等于完成 AUF

六格先回答“这是什么 PLL”，AUF 再回答“我的公式从哪个方向起手”。两件事混在一起，会出现案例认对却把公式从错误方向做出的情况。

没有一条适用于所有人的固定 AUF 口令，因为同一 PLL 可以选不同公式和不同起手面。更可靠的做法是给自己的每条公式只绑定一个**锚点**：

- 例如“3 格条放后面”“车灯放左边”“唯一 2 格块贴右手”。
- 六格认出案例后，用 `U / U' / U2` 把锚点送到公式要求的位置。
- 熟练后把识别和 AUF 合并：看到锚点所在方向时，手已经知道第一下该转哪边。

不要为了找熟悉图案转动整颗魔方。整颗转动会改变正面与右面的定义，还会增加重新定位公式起手面的时间。

## 四阶段训练法

### 1. 只练角块分组

随机出现 PLL 时只回答“角归位 / 对角换角 / 相邻换角”，暂时不报案例名。目标是从四颗角贴直接分类，不再环视四面。

### 2. 分三批加入案例

按 `EPLL 4 个 → 对角换角 5 个 → 相邻换角 12 个` 的顺序学习。相邻换角内部先练 `J / T / F / R / A`，最后集中处理四个 `G`。

### 3. 强制只看两个相邻面

训练器中随机切换四个观察方向和侧面颜色。即使一开始要想很久，也不要转动视角偷看第三面；否则练到的仍是四面搜索习惯。

### 4. 单独记录混淆对

不要只记总正确率。把错题写成成对问题，例如 `V ↔ Y`、`Ga ↔ Gc`、`Gb ↔ Gd`、`Ra ↔ Rb`，下一轮只练这两个家族，并说出真正区分它们的那一枚贴纸。

练习时可以使用 [SpeedCubeDB 两面识别训练器](https://speedcubedb.com/t/pllrecog)；若需要按特征类别和混淆项加权，可使用 [SpeedcubeQuest PLL Recognition Trainer](https://speedcube.quest/trainers/pll-recognition)。先关闭计时做准确率，再逐步压缩识别时间。

## 常见误区

- **背绝对颜色。** “红绿红”只在一个配色和一个方向下成立；应记“车灯夹相邻色”。
- **把车灯当成 3 格条。** 车灯只要求两颗角同色；中间棱也同色时才是 3 格条。
- **看到同色就当色块。** 2 格块必须相邻；隔着一格同色是车灯，不是块。
- **为了确认而转整颗魔方。** 六格信息已经足够。犹豫说明某个分支还没练熟，不是信息不足。
- **只会认标准观察角度。** 每个案例必须覆盖四个 `U` 方向和多组侧面颜色。
- **案例认对但公式做错方向。** 这是 AUF 锚点问题，应该单独练“识别后把锚点送到起手位”。
- **四个 G 总靠猜。** 先找唯一块或车灯，再判断块旁角是相邻色还是相对色，最后看左右；不要直接从整体颜色猜字母。

## 一张脑内流程图

每次 OLL 结束，只执行这条流程：

1. 看四颗角贴：`双车灯 → EPLL`，`两面对角均为相对色 → 对角换角`，其余为相邻换角。
2. 在该分组内依次找：`3 格条 → 车灯 → 2 格块 → 书挡`。
3. 仍有多个候选时，只补看一项：`相邻 / 相对、三色 / 四色、棋盘位置、左右方向`。
4. 报出案例，用自己的公式锚点完成 AUF，然后起手。

当你能稳定说出“角块分组 + 最强特征 + 唯一区分贴纸”，六格观察就不再是一张需要背诵的表，而会变成一次固定、短促的视觉判断。
