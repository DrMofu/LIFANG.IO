## System support

| System | Support status | Recommended browser | Notes |
| --- | --- | --- | --- |
| Windows 10 / 11 | ✅ Supported | Chrome, Edge | - |
| macOS | ✅ Supported | Chrome, Edge | - |
| ChromeOS | ✅ Supported | Chrome | - |
| Android 6.0 and later | ✅ Supported | Chrome | - |
| iOS / iPadOS | ✅ Supported | Bluefy | iPhone and iPad require the Bluefy browser to connect to smart cubes |
| Linux | ⚠️ Experimental support | Chrome, Chromium | Experimental Web Platform features may need to be enabled in the browser |

## Features

- Connect to smart cubes and view their state in real time
- Time your solves and track statistics for each solving stage
- Browse and practice CFOP algorithms
- Practice individual CFOP stages
- Access from desktop computers, tablets, and phones

> [!NOTE]
> Currently, only GAN smart cubes are supported. Chrome is recommended on desktop and Android devices. iPhone and iPad require the Bluefy browser.
